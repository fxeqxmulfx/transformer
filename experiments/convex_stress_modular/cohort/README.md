# Original pair-table cohort for composite categorical codes

This native harness applies the same CM27 code and CM25 strip policy to all
23 original eligible pair-table tasks, including power division and recurrence. It receives
only observed categorical cell/class identities. Task names select the original
frozen dataset; no arithmetic interpretation of token names enters discovery.
Lean98b12abc precedes the integer core and the tested observed-only learner.

The complete full105 integration is an immutable parent. Preparation requires
its pinned summary digest, copies every byte and validates all35 task identities
in all three modes. All earlier candidates, refusals and outcomes remain in that
complete parent. For each new case, the constructor receives only training
observations; its accepted models use the original vocabulary and unit-logit
ordinary CE. Each mode keeps its earlier choice first, then considers the new
candidates. A replacement requires a CE improvement greater than1e-12. The
harness seals these references before evaluating new held-out metrics.

The default code policy retains4096 original equations, eight finite stages,
500 million scalar updates per stage, two billion overall and two million row
operations per stage. It requires one-dimensional normalized prime components,
unique digit lifts, checked CRT and distinct class codes. All observations are
checked at the final endpoint, including those beyond the equation cap. The
strip wrapper uses support8 and at most four views, retaining skipped, empty,
refused and duplicate views. All raw spectra and ordinary CE are audited.
These are bounded proposals inside the convex prediction hull; their discrete
search has no global convexity or unseen-identification guarantee.

Each case runs once, with three comparison references and zero CE gradients.
Full replay regenerates original data/fingerprints, checks all integer/strip
certificates, repeats every state/work decision and recomputes all raw audits
and split metrics. Summarization requires every terminal outcome and each
successful replay binding. A failed process retains its earlier three choices.
The summary covers all105 choices; the other36 keep their complete parent result.
Retained depth and conventional-transformer integration remain separate pending
requirements of the full goal.

Five harness checks use synthetic inputs only: default policy/data fingerprint;
masked composite strips with complete state replay and earlier-parent CE ties;
rehash-resistant state/input/parent tampering; all23 process failures preserving
all105 choices; and a successful result changing only three choices with artifact
and byte-limit checks. The native core/wrapper has15 additional tests.
