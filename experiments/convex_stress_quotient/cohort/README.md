# Serial catalogue preparation

This native component runs the complete fixed55-prime catalogue, one binding
report at a time. Task231 also connects original data and metrics to a complete
reviewed parent, retaining both initializer arms and all35 tasks. Sixteen native
fixture tests pass and the independent review is approved at `49105730`.
Task232's frozen original cohort has started; no new benchmark result is claimed.

Each stage retains its original request, discovery outcome, actual complex
model, all three CE endpoints, audits and original-row certificates. Returned
errors are saved explicitly and cannot be treated as model results. A compact
ledger holds hashes, work counters, every refusal and elapsed stage times; it
never keeps all dense reports resident. Observed-CE selection uses increasing
prime order and earlier ties separately for full/mini/forward. It cannot read
held-out targets. Construction, training and checking time is charged once per
stage; measured time is preserved rather than recomputed during replay.

The native source inventory includes the component, its immediate numerical
dependencies, the runner and protocol, plus both existing shared-source
fingerprints. Metadata also pins the executable, configuration and producer
commit. Replay checks all55 original reports, including errors/caps, recomputes
actual saved-state semantics and reconstructs the compact ledger and CE choice.
A changed model still fails after its outer hashes are rewritten.

Five tests cover the entire55-stage catalogue. A six-class fixture admits both
two-state and three-state quotient codes; all modes select the three-state
head by observed raw-label CE, while retaining the other successful proposal
and all53 refusals. Separate tests cover all55 returned policy errors,
elimination caps, changed states after rehashing, removed stages, altered work,
source/configuration changes, oversized files, and earlier CE ties regardless
of certificates or held-out metadata.

Three further tests exercise the parent selector, for eight tests in total.
Each of the two initializer policies keeps its own105 choices across35 tasks
and three modes. New offers use increasing prime order and replace that arm's
parent only on a training-CE decrease greater than1e-12. The selector preserves
missing models, checks336 retained/original depth slots and35 transformer
endpoints, and rejects missing, duplicate, unknown or invalid score records.
Held-out fields and certificate flags cannot affect its choices.

Eight additional tests exercise the original adapter with synthetic evidence.
They retain both105-choice arms, all336 depth outcomes, all35 transformer
endpoints, eight complete ancestor snapshots and five immediate parent files.
The parent source, frozen executable, summary, manifest, request, selection,
successful independent review and artifact inventory must agree. Mutating a
model, ancestor, review or copied parent is rejected. A process failure or
failed numerical replay keeps all six prior choices and its partial artifacts,
logs, resource records and failed replay evidence. Constructor costs are charged
once across both arms, including unused codes and incompatible proposals.

The native generator rebuilds the unchanged original categorical pairs and
checks their frozen data fingerprints. Only observed input names and raw labels
enter discovery, latent features, initialization and CE updates. Every proposed
endpoint is evaluated with the existing complete-split evaluator. Primary and
all-split passes use its original99% rule; no code certificate substitutes for
an observed benchmark result. Independent replay recomputes the entire catalogue,
every CE step, actual model state, certificate and original metric. Rehashed
metric, score, eligibility, success-claim and saved-state changes are rejected.

Before the observed-CE selector, the adapter checks that the original declared
readout is constant on a candidate code's observed raw-class fibers. Ordinary
tasks use the identity readout. Tasks declaring the original residue-pooling
metric use that evaluator's token groups `(token - vocabulary/2) mod97`.
Adding the per-example base permutes those groups, so the eligibility check
needs neither that base nor its future answer. This map does not enter model
features, labels, the softmax, CE or gradients. It only filters candidate offers;
every incompatible constructed model is still retained and evaluated. After
this filter, selection uses observed raw CE and earlier ties only, separately
within each parent initializer policy. References are sealed before evaluation.

The pooled-metric fixture has six raw classes sharing three latent states,
embedded in101 output classes. Its compatible code passes every original-style
decoded split in full, mini and forward modes, while its held-out raw-token
accuracy is zero and raw training CE exceeds0.6. This checks the metric/code
boundary, not the original recurrence task. Candidate compatibility does not
prove the unknown target's additive representation or compatible code; those
remain CM30 premises. Original code discovery, CE convergence and pooled-mass
argmax correctness are not consequences of the Lean theorem.

The generic CLI accepts a serialized `Configuration`; the shell runner caps
both construction and replay at64GiB. It creates new output files only. Files
are streamed with an8GiB limit. Generated artifacts remain local and ignored.
Binary/cache parent artifacts have a separate16GiB per-file hash limit.
Parent artifacts are fully rehashed at preparation and final summary. Each
individual case binds the frozen parent and copied snapshots without rereading
all of its large feature caches. Stage reports are streamed one at a time.

Original launch requires board tasks226,230 and231 approved, a fresh destination,
and a prospective source/binary/protocol/request freeze. The protocol fixes23
eligible categorical pair tasks; every other original task retains its reviewed
parent in both arms, along with all transformer and historical costs. All55
prime stages are attempted per case; no modulus is selected from the task name.
There are no arithmetic answer features. Runs and replays are serial, each with
the64GiB address-space cap and16GiB disk reserve before a new case.
